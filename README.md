# Jt-app - Cinéma Studio 901

Bienvenue sur le dépôt de l'application **Cinéma Studio 901**, une application web autonome (fichier unique HTML) permettant de générer des vidéos et des journaux télévisés (JT) en utilisant l'intelligence artificielle d'Agnes AI.

## 🚀 Fonctionnalités principales
- **Génération de JT** : Crée des séquences vidéo à partir de l'actualité (LFI, news générales).
- **Multi-Clés API** : Prend en charge plusieurs clés API Agnes en même temps pour accélérer la génération en parallèle.
- **Personnages récurrents** : Génère des présentateurs et des reporters (chatons kung-fu casqués dans le style Wes Anderson).
- **Player intégré** : Lit les vidéos en séquence avec une narration vocale (TTS) en français.
- **Interface complète** : Console de débogage, gestion des erreurs, et analyse d'images de référence.

## 🛠️ Comment l'utiliser ?
1. Télécharge le fichier `Indes.html` présent dans ce dépôt.
2. Ouvre-le dans n'importe quel navigateur web (Chrome, Safari, Firefox).
3. Colle ta ou tes clés API Agnes dans le champ prévu à cet effet.
4. Clique sur "Lancer le journal" et laisse l'IA travailler !

*Note : Une clé API gratuite peut être obtenue sur [platform.agnes-ai.com](https://platform.agnes-ai.com).*
